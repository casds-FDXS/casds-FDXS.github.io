# FDXS Personal Site

A lightweight personal website for presenting projects, development interests, and current experiments.

## Status

Early draft.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

## Local Preview

```powershell
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Current Content

* Personal introduction
* Current focus
* Selected projects
* Working style
* Contact placeholder

## Privacy

This site does not include private contact information, analytics, tracking scripts, or private project repository links.
